# Customer Segmentation & Retention Analysis using PostgreSQL

**SQL Portfolio Project | PostgreSQL | RFM Analysis | Customer Analytics**

## Project Overview

This project analyzes customer purchasing behavior for a UK-based online retailer using PostgreSQL and **RFM (Recency, Frequency, Monetary) Analysis**.

The objective is to identify valuable customer segments, evaluate their contribution to sales, and recommend data-driven marketing strategies to improve customer engagement and retention.

### Key Results

- **541,909** original retail transaction records analyzed.
- **4,338** customers segmented into **6 behavioral groups**.
- **21.81%** of customers (Champions) contributed **64.48% of gross positive sales (£5.75M)**.
- **659 at-risk customers** identified, representing **£822K in historical purchases**.
